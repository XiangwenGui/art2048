# 2048 · 名画家版

用 10 位艺术家代替数字的 2048，越早出生的画家阶位越高：

达利 4 → 毕加索 8 → 梵高 16 → 莫奈 32 → 维米尔 64 → 伦勃朗 128 → 卡拉瓦乔 256 → 拉斐尔 512 → 米开朗基罗 1024 → **达·芬奇 2048** → 波提切利 4096 → 凡·艾克 8192 → 乔托 16384 → **拉斯科洞穴 32768**

还没解锁的画家，可以点击下方阶梯里的问号“提前查看”介绍（会标成虚线框）。

## 文件
- `index.html` 页面结构
- `style.css` 样式
- `game.js` 游戏逻辑与画家资料（改介绍文字就改这里的 `A` 数组）
- `manifest.json` + `sw.js` + `icons/` 让它能“添加到主屏幕”并离线运行
- 右上角按钮切换中文 / English；英文介绍在 `game.js` 的 `EN` 数组，界面文字在 `I18N`
