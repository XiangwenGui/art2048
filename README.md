# 艺术时光2048 · 2048 Art Through Time

纯 HTML/CSS/JS，直接放到 GitHub Pages 即可。

- `index.html` 页面结构
- `style.css` 样式（游戏主界面一屏不滚动；画廊、画家卡片、结算页可以上下滚动）
- `data.js` 17 位画家的介绍、作品信息、图片来源（由任务清单“介绍文字”正式版生成）
- `game.js` 游戏逻辑：17 阶（2 → 131,072）、拼图块、颜料、画廊、新手引导、中英双语
- `img/full/` 作品图（长边 2000px），`img/thumb/` 画廊缩略图
- `sw.js` 离线缓存（改动文件后把版本号加一）

可调的数字在 `game.js` 开头：`PIECE_COST`（每块高阶拼图需要的颜料，现为 17,000）、`HIGH`（高阶从第几阶开始）。
存档用的是新的键名（oma_*），和旧版 14 阶的存档互不影响。
